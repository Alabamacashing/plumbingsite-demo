# ProFlow Plumbing demo site

A static plumbing-services landing page built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with a static file server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

The project has no build step. Deploy the project root to Vercel:

```sh
npx vercel --prod
```

Replace the demo phone number, email address, service area, and sample reviews in `index.html` and the contact email in `main.js` before using this as a real business website.
